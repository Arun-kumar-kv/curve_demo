# Curve Demo 🚀

A backend analytics and lead management system built using **FastAPI**, **MySQL**, and **Python**, designed to power real-time dashboards and business insights.

---

## 📌 Features

- 📊 Lead analytics (daily / monthly trends)
- 🏢 Property & booking insights
- 💰 Revenue summary APIs
- 📈 Dashboard-ready endpoints
- ⚡ High-performance FastAPI backend
- 🔐 Secure database connection using SQLAlchemy / MySQL Connector

---

## 🛠 Tech Stack

- **Backend:** FastAPI
- **Language:** Python 3.9+
- **Database:** MySQL
- **ORM / DB Access:** SQLAlchemy, mysql-connector-python
- **Data Processing:** Pandas, NumPy
- **Server:** Uvicorn
